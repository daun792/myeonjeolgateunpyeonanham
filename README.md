## Windows에서 빌드 및 단위 테스트

Android SDK 37, JDK 25와 Gradle Wrapper를 사용합니다. Android Studio에서 SDK 경로를 설정하거나 프로젝트 루트의 `local.properties`에 `sdk.dir`을 지정합니다. 이 파일은 각자 환경에 맞게 설정하며 Git에 포함하지 않습니다.

이 PC처럼 프로젝트 경로에 한글이 포함된 Windows 환경에서는 Gradle 테스트 실행기의 클래스 경로 인코딩 문제를 피하도록 앱의 빌드 출력 폴더를 영문 경로로 지정할 수 있습니다. 아래 설정은 현재 PowerShell 세션에만 적용되며, `PRIVACY_APP_BUILD_DIR`을 지정하지 않으면 기본 출력 폴더인 `app/build`를 사용합니다.

```powershell
$env:JAVA_HOME = 'D:\Android\android-studio\jbr'
$env:GRADLE_USER_HOME = 'D:\Android\gradle'
$env:PRIVACY_APP_BUILD_DIR = 'D:\Android\build\privacy-app'
.\gradlew.bat :app:testDebugUnitTest
.\gradlew.bat :app:assembleDebug
```

에뮬레이터 시연 환경은 Pleos Connect 2.1.0, Android API 34, 2560×1440입니다. 이 앱은 최소 Android API 28을 지원합니다.

## 현재 구현 범위

프리셋을 추가·선택·이름 변경·순서 변경·삭제하고, 보호 대상·자동 실행·오디오 보호·잠시 보기 설정을 프리셋별로 저장할 수 있습니다. 설정 화면의 변경은 저장할 때 반영되며 취소하면 버립니다. 마지막으로 선택한 프리셋은 앱을 다시 열어도 유지됩니다.

홈에서 차량 기본 화면 시뮬레이션을 열 수 있습니다. 선택된 프리셋의 잠시 보기 범위에 한해 버튼을 누르는 동안 예시 내용을 표시하며, 손을 떼거나 터치가 취소되고 화면 포커스를 잃으면 다시 가립니다. 지도와 우회전 안내는 항상 표시됩니다. 이 화면은 예시이며 실제 차량 기본 화면은 제어하지 않습니다.

설정과 보호 요청은 로컬에만 저장됩니다. 차량 시스템, 다른 앱의 개인정보 가림, 통화 음성 처리, 자동 감지 및 잠시 보기 동작은 아직 연동되지 않았습니다. 사진 승인 관리는 준비 중입니다.

홈과 알림 설정에서 보관 알림 화면을 열고 앱 내 테스트 알림을 생성·보관·삭제할 수 있습니다. 이는 개인정보가 없는 고정 예시이며 앱 전용 저장소에는 식별자와 생성 시각만 저장합니다. 테스트 알림의 건수는 ‘테스트’라고 명시합니다. 실제 시스템 알림 수집과 보관, 보호 적용 상태 및 주차 상태는 연동 전이며 알림 내용은 공개하지 않습니다. 향후 연동 시에는 실제 보호 해제와 주차가 모두 확인된 뒤 사용자가 선택한 항목만 확인할 수 있습니다.

차량 상태를 실제로 연결할 때는 목록 화면이 받은 상태가 고정된 스냅샷임에 주의해야 합니다. 상세 내용이 열린 뒤 보호 상태나 주차 상태가 바뀌면 즉시 내용을 닫고, 선택할 때 최신 상태를 다시 확인하는 처리가 필요합니다.

설치된 환경과 PLEOS SDK·알림 권한의 확인 범위는 [PLEOS 연동 확인 사항](docs/pleos-integration.md)을 참고하세요.
